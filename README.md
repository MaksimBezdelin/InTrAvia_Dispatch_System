# InTrAvia Dispatch

**Smart Dispatch System** — система интеллектуальной диспетчеризации инженерных
заявок для аэропорта. Проект реализует полный цикл работы с заявками на
обслуживание воздушных судов: от голосовой заявки командира ВС до отчёта
инженера о диагностике.

---

## 🔗 Демо-версия

Проект развёрнут в облаке и доступен по ссылке:

**https://intravia-dispatch-system-1.onrender.com**

На этой версии работают все основные функции:
- авторизация и разграничение ролей (админ / диспетчер / инженер / пилот);
- создание заявок диспетчером;
- назначение инженеров по специализации;
- карта с маркерами инженеров и спецтранспорта;
- отчёты о диагностике;
- задержки рейсов и отмена рейса;
- заявки от командира ВС с голосовым сообщением;
- журнал отменённых заявок.

### ⚠️ Ограничение облачной версии

**Функция распознавания речи (Whisper) в облаке отключена.**

Причина — техническое ограничение бесплатного тарифа Render:
в среде Python-рантайма нельзя установить системный пакет `ffmpeg`,
который нужен для конвертации аудио перед отправкой в Whisper.
Поэтому на облачной версии голосовые заявки от КВС **записываются и
сохраняются**, но автоматическая расшифровка в текст не работает —
диспетчер увидит пометку «Whisper не установлен».

## 🖥️ Локальный запуск с расшифровкой голоса

Если вы хотите протестировать **полный функционал, включая
автоматическое распознавание речи**, запустите проект локально.

### Шаг 1. Установите ffmpeg

Скачайте `ffmpeg` и положите его, например, сюда:
C:\Users\deela\AppData\Local\Microsoft\WinGet\Links\ffmpeg.exe

text

Этот путь прописан в `app.py` в константе `FFMPEG_PATH_WINDOWS`.
Если вы положили ffmpeg в другое место — откройте `app.py` и поправьте
путь в этой константе.

Проверить, что ffmpeg работает, можно командой в терминале:
"C:\Users\deela\AppData\Local\Microsoft\WinGet\Links\ffmpeg.exe" -version

text

Должна вывестись версия ffmpeg.

### Шаг 2. Установите Python-зависимости

```bash
pip install -r requirements.txt
```
### Шаг 3. Запустите сервер
```bash
python app.py
```
В консоли должно появиться:

```text
[FFMPEG] Найден: C:\Users\deela\...\ffmpeg.exe
[FFMPEG] Добавлено в PATH: C:\Users\deela\...\Links
[DB] Инициализация завершена
 * Running on http://127.0.0.1:5000
```
### Шаг 4. Откройте браузер
Важно: переходите именно по адресу

```text
http://localhost:5000
или

text
http://127.0.0.1:5000
Не открывайте по IP (например, http://192.168.х.х:5000) — в этом случае
браузер не даст доступ к микрофону, и запись голосовой заявки пилота
не будет работать. Микрофон разрешён только на localhost и https://.
```
